### Switches

- `GOLF_NP=offline`: signed-out console instead of the local account. The launcher passes it (`--np-mode offline`) when Online is Off: signed in with no server, the game showed "Server connection failed" on the island at a random moment, and the dialog took the next Cross presses. `GOLF_ONLINE_ID=<name>`: the local online id (default `Golfer`).
- `GOLF_ENTITLEMENTS=original`: report no add-ons. A save that holds add-on items will not load in this mode (the game names the missing items).
- `RESOGUN_IME_TEXT=<text>`: answer every keyboard dialog with this text (needed for unattended boots: the on-screen dialog waits for a real controller or keyboard).
- `RESOGUN_FILE_TRACE_MATCH=<text>`: log every open whose path contains the text, found or not.
- `RESOGUN_FAULT_PEEK=<reg><+|->0x<offset>`: print the string at that address in a fault report.
- `RESOGUN_VERIFY_PREPARED=1`: compare what the draw-preparation workers read with a fresh read and log differences.
- `RESOGUN_NGS2_TRACE=1`: print the Ngs2 voice parameters the game sends. `RESOGUN_NGS2_MIX=0`: silent output. `RESOGUN_AUDIO_DUMP=<prefix>`: raw samples of every audio port.
- `GOLF_NP_TRACE=1`: log each distinct guest call site of the shared NP answers. `GOLF_PEEK="offset:bytes,*offset+delta:bytes"` (hex, `*` follows the pointer stored there) prints guest memory ranges when they change, every `GOLF_PEEK_MS` ms (default 2000). `GOLF_BREAK="d91790,a62080"` (hex guest offsets, up to 8, Windows) puts an int3 on each site and prints the thread, rdi, rsi, rdx, the u32 at rsi+0x18 and the caller for the first 40 hits, then re-arms after one step (runtime `8136a31`).
- `RESOGUN_TOGGLE_FILE=<file>`: a number in the file switches renderer optimizations off while the game runs (bits in `gpu/shim/resogun_toggles.h`).

- Face patches fixed (2026-11-19, runtime `f55f73d`). Cause: cube-map sampling. The face shaders read image-based lighting from a cube map (image 73, GCN cube math, explicit LOD from the surface roughness). The runtime treated every guest cube map as a 2D array and sampled one face at a time, with the guest sampler's Wrap mode, so filtering at a face edge blended in the opposite edge of the same face instead of the neighboring face. Rough skin reads the low mips, where a face is a few texels wide, so each cube-face boundary drew a straight seam. A plane through a roughly round head projects to a straight line, which is why the seams ran down the cheek and neck. Zeroing samples 67 to 110 removed the seam. Zeroing 11 to 66 did not. The fix lives in `ImageResource::IsCubeSampled`. A cube map read only by normalized sampling is now declared as a SPIR-V cube array, its coordinates are turned back from (face, s, t) into a direction, and it gets a cube-array view of a cube-compatible image. Square 2D images with six or more layers are now cube-compatible. After the fix the shop clerk's face and neck, the shop mannequin and the island statues render without seams (`work/evidence/face-cube-fix-*-1119.png`, local only). The before/after comparison uses the same every-third-column sampling, since the before frame came from a debug run. No cube view fell back to a 2D array in that run (the runtime logs it once if one does). The Challenge setup screen, where the neck patches were first seen, now shows the player's face and neck without seams (`face-cube-fix-challenge-1119.png`).
